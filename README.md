\# C++ Practice



A collection of beginner-level C++ programs written while learning programming fundamentals.



\## Topics Covered



\- Basic input and output

\- Variables and data types

\- Arithmetic operations

\- Integer and floating-point division

\- Boolean expressions and logical operators

\- Conditional statements

\- Type conversion

\- Mathematical calculations



\## Practice Programs



| File | Description | Concepts |

|---|---|---|

| `program.cpp` | Hello World | Basic output |

| `d4speed.cpp` | Calculate distance using speed and time | Arithmetic |

| `d9plumber.cpp` | Calculate a service charge | Arithmetic |

| `d10.cab.cpp` | Calculate cab fare | Arithmetic |

| `d11subject.cpp` | Calculate the average of three subjects | Integer and floating-point division |

| `d12carmileage.cpp` | Calculate vehicle mileage | Arithmetic |

| `d13thermometre.cpp` | Convert Celsius to Fahrenheit | Type conversion |

| `d14elec.cpp` | Calculate electricity charges | Arithmetic |

| `d15bike.cpp` | Check bike riding eligibility | Boolean logic and conditions |

| `d16scholarship.cpp` | Check scholarship eligibility | Logical AND operator |

| `d19houminsec.cpp` | Convert seconds into hours, minutes and seconds | Division and modulus |



\## Tools Used



\- C++

\- GCC / G++

\- Visual Studio Code

\- Git and GitHub



\## How to Compile and Run



Compile a program:



```bash

g++ d4speed.cpp -o d4speed.exe

```



Run it in PowerShell:



```powershell

.\\d4speed.exe

```
